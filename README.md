# Personal website

Personal landing page for [Clément Duvivier](https://www.clementduvivier.com).

## Frameworks & tooling

- [Next.js](https://nextjs.org/) 16 (App Router, Turbopack in dev)
- [React](https://react.dev/) 19
- [TypeScript](https://www.typescriptlang.org/) 5
- [Tailwind CSS](https://tailwindcss.com/) 4
- [ESLint](https://eslint.org/) 9 with `eslint-config-next`
- [pnpm](https://pnpm.io/) 10

## Packages

**Dependencies**

- `next` — React framework and routing
- `react` / `react-dom` — UI runtime
- `@vercel/speed-insights` — Web Vitals on Vercel

**Dev dependencies**

- `tailwindcss`, `@tailwindcss/postcss`, `postcss` — styling
- `typescript`, `@types/node`, `@types/react`, `@types/react-dom` — types
- `eslint`, `eslint-config-next`, `@eslint/eslintrc` — linting

## Hosting

Deployed on [Vercel](https://vercel.com/).
